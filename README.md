The goal of Enchantments Rebalanced is to improve enchantments in various ways without changing the system beyond recognition.

**This data pack is very new and needs plenty of constructive feedback, whether it's positive, mixed, or negative. Please join the Discord server and share your thoughts or suggestions!**

### Changes
- Mending and Unbreaking 3 are mutually exclusive
- All anvil costs for enchantments have been adjusted
  - This, for the most part, makes lower tier enchantments add 1-2 levels, medium tier add 3-4, and high tier add 4-8 levels.
